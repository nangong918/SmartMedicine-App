**Redisson**
============

## Redisson的数据结构


| Redisson 数据结构 | Redis 数据结构   | 适用场景                                                                                                           |
| ----------------- | ---------------- | ------------------------------------------------------------------------------------------------------------------ |
| RBucket           | String           | 存储单个对象或简单值，如用户会话、配置信息等。适合快速查找和存储。<br />也可以存储JSON对象来序列化反序列化Java对象 |
| RMap              | Hash             | 存储键值对，适合需要快速查找和更新的复杂对象                                                                       |
| RSet              | Set              | 存储多个唯一元素，适合需要集合操作的场景，如用户的关注列表、标签等                                                 |
| RList             | List             | 存储有序集合，适合需要保持顺序的场景，如历史记录、消息队列等                                                       |
| RSortedSet        | Sorted Set(ZSet) | 存储有序的唯一元素，适合需要排序和排名的场景，如排行榜、延迟队列等。                                               |
| RQueue            | List             | 实现消息队列，适合生产者-消费者模式的场景，如任务调度、消息处理等。                                                |
| RDeque            | List             | 双端队列，适合需要从两端插入或删除元素的场景，如任务优先级队列等。                                                 |
| RMultiMap         | Hash of Sets     | 允许一个键映射到多个值的集合，适合多值映射的场景，如用户的多个电话号码。                                           |
| RAtomicLong       | String           | 原子操作的长整型数值，适合计数器、限流等需要同步的场景。                                                           |
| RLock             | Distributed Lock | 分布式锁，适合需要在分布式环境中保护共享资源的场景。                                                               |
| RCountDownLatch   | CountDownLatch   | 实现倒计时功能，适合需要协调多个线程或任务的场景。                                                                 |
| RSemaphore        | Semaphore        | 实现信号量，适合控制并发访问的场景，如限制同时访问的客户端数量。                                                   |

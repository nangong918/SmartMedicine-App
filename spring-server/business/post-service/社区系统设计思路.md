# Post模块设计
数据存储:
Mysql存储基本postInfo信息
minio存储file数据
mongoDb存储文章信息.

* 分析为什么要用MongoDB
MongoDB存储Json格式, 字段比较灵活, 但是代价是JOIN联合查询不能实现.
此处post查询都是用id去直接获取, 不会出现JOIN
并且post文章需求很可能出现文章本身内部哪里在哪行是存在图片的这种，mysql是不好实现的, 但是mongodb就好实现.
```json
{
  "id": 1000,
  "title": "心脑血管疾病问题如何解决",
  "postContents": [
    {
      "text": "第一段内容",
      "image": {
        "fileId": 1,
        "description": "图片说明1"
      }
    },
    {
      "text": "第二段内容",
      "image": {
        "fileId": 2,
        "description": "图片说明2"
      }
    }
  ],
  "nerResults": [
    {
      "keyWord": "心脏病",
      "nerType": "疾病",
      "score": 0.95
    },
    {
      "keyWord": "脑科",
      "nerType": "部门",
      "score": 0.90
    }
  ]
}
```
这样就能灵活的存储图片文章及其对应的图片信息位置的, 这一点是mysql不能实现的,即便实现也是用json, 还不如用mongoDb
其对应的存储Java对象
```java
import java.io.Serializable;
import java.util.List;

// 图片信息类
@Data
public class PostImage{
    public Long fileId;
    public String description;
}

// 内容段落类
@Data
public class PostContentEntity {
    public String text;
    public PostImage image;
}

// 文章画像标签
@Data
public class PostNerResult implements Serializable {
    private String keyWord;
    private String nerType;
    private Double score;
}

// 主文章类
@org.springframework.data.mongodb.core.mapping.Document("post_detail")
@Data
public class PostDetailDo implements Serializable {
    // id；postDetails的id与postInfo的id一致
    @Id
    private Long id;
    // title；not null
    private String title;
    // contents；not null
    private List<PostContentEntity> postContents;
    // ner特诊
    private List<PostNerResult> nerResults;
}
```

* 关于点赞等这些高频度改变查询且没什么用的数据
存储在Redis中, 将数据结构转为Hash存储
```java
@Data
public class PostVo implements Serializable {
    public Long postId = null;
    public String postViewNum = "0";
    // 点赞数量
    public String likeNum = "0";
    // 收藏数量
    public String collectNum = "0";
    // 评论数量
    public String commentNum = "0";
    // 转发数量
    public String forwardNum = "0";
}
```
将Hash数据存储到Redis
```java
    // 存储 PostVo 到 Redis
    public void savePostVo(PostVo postVo) {
        RHash<String, String> postHash = redissonClient.getHash("post:" + postVo.getPostId());
        postHash.put("postViewNum", postVo.getPostViewNum());
        postHash.put("likeNum", postVo.getLikeNum());
        postHash.put("collectNum", postVo.getCollectNum());
        postHash.put("commentNum", postVo.getCommentNum());
        postHash.put("forwardNum", postVo.getForwardNum());
    }

    // 更新点赞数量
    public void incrementLikeNum(Long postId) {
        RHash<String, String> postHash = redissonClient.getHash("post:" + postId);
        postHash.hincrby("likeNum", 1);
    }

    // 更新阅读数量
    public void incrementViewNum(Long postId) {
        RHash<String, String> postHash = redissonClient.getHash("post:" + postId);
        postHash.hincrby("postViewNum", 1);
    }

    // 获取 PostVo
    public PostVo getPostVo(Long postId) {
        RHash<String, String> postHash = redissonClient.getHash("post:" + postId);
        PostVo postVo = new PostVo();
        postVo.setPostId(postId);
        postVo.setPostViewNum(postHash.get("postViewNum"));
        postVo.setLikeNum(postHash.get("likeNum"));
        postVo.setCollectNum(postHash.get("collectNum"));
        postVo.setCommentNum(postHash.get("commentNum"));
        postVo.setForwardNum(postHash.get("forwardNum"));
        return postVo;
    }
```
